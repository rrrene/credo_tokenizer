# CredoTokenizer

This is a "fork" of Elixir's tokenizer, which is a private API of the Elixir compiler.

For the time being, this should be considered a private API for Credo.

## Installation

If [available in Hex](https://hex.pm/docs/publish), the package can be installed
by adding `credo_tokenizer` to your list of dependencies in `mix.exs`:

```elixir
def deps do
  [
    {:credo_tokenizer, "~> 0.1.0"}
  ]
end
```

Documentation can be generated with [ExDoc](https://github.com/elixir-lang/ex_doc)
and published on [HexDocs](https://hexdocs.pm). Once published, the docs can
be found at <https://hexdocs.pm/credo_tokenizer>.
